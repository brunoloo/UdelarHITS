# Política de seguridad

## Reportar una vulnerabilidad

No abras un issue público para reportar un problema de seguridad.

Usá el reporte privado de vulnerabilidades de GitHub (pestaña **Security** del repositorio, opción **Report a vulnerability**) o escribí a udelarhits@gmail.com.

Incluí, en lo posible:

- una descripción del problema y de su impacto;
- los pasos para reproducirlo o una prueba de concepto;
- la versión o el commit afectado.

Vas a recibir una respuesta dentro de los 7 días. Te pedimos que no divulgues el problema hasta que haya una corrección publicada.

## Alcance

Están dentro del alcance el código de este repositorio y el sitio udelarhits.com.

Al investigar, no accedas a datos de otros usuarios, no degrades el servicio y no uses ingeniería social. Las pruebas automatizadas de alto volumen contra el sitio en producción quedan fuera del alcance.

## Versiones con soporte

Solo recibe correcciones de seguridad la última versión de la rama `main`.
